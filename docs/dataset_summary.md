# Dataset Summary

## 1. State Farm Distracted Driver Detection
- Source: Kaggle
- Total images: ~22,000
- Classes: 10 (c0: safe, c1-c9: distracted behaviors)
- Format: JPG, 480x640
- Stored at: data/raw/statefarm_distraction/

## 2. CEW Dataset (Closed Eyes in the Wild)
- Source: Kaggle
- Purpose: Eye state detection (open/closed)
- Stored at: data/raw/cew_eyes/

## 3. NTHU Drowsy Driver Dataset
- Source: NTHU official site
- Purpose: Drowsiness detection from video
- Stored at: data/raw/nthu_drowsy/
