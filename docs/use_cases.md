# Use Cases

## Driver Safety
- Drowsiness alert before microsleep
- Distraction warning (phone, eating, looking away)
- Stress level monitoring via rPPG
- Medical emergency detection (sudden HR change)
- Fatigue scoring over long trips

## Occupant Safety
- Seatbelt compliance per seat
- Child seat detection and airbag suppression
- Infant left alone detection
- Occupant count for routing
- Crash response — detect unconscious occupants

## Fleet & Commercial
- Truck driver fatigue monitoring
- Bus driver distraction alerts
- Insurance telematics — safe driving score

## Autonomous Vehicle
- Driver takeover readiness detection
- Emergency stop if driver incapacitated
